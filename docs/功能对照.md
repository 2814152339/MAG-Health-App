# 2026-11-10 规划 → 本次 iOS 工程

本次为第一版开发工程；以下按原规划 F01–F35 对照实际代码。完整原始技术条目保存在 `planning-features.json`，不包含参考视频或用户面部截图。

## 原生采集与几何

- **F01 入口/引导/隐私**：已实现首页、首次同意、隐私说明、删除与自选服务器设置。
- **F02 前置拍照/原图上传**：已实现 AVFoundation、前后切换、重拍确认、单图相册选择；同意并主动启用服务端后上传。分析用统一朝向的处理版 JPEG，最长边 2560，不宣称逐字节保留原件。
- **F03 质量门控**：已有单人、面部尺寸、姿态、边缘裁切、曝光检查；清晰度为阈值提示。遮挡/戴镜/妆容专项模型及跨机型阈值评测待接入。
- **F04 点位/扫描**：已有真实五官点位、分阶段进度、扫描交互；进度由算法/任务阶段驱动。未实现前摄实时视频逐帧跟踪。
- **F05 脸型/面部尺寸**：已有二维长度比例，不输出未经验证的脸型标签和毫米尺寸；完整面部轮廓/额宽需要更完整的关键点与发际线模型。
- **F06 下颌**：已有真实下颌轮廓线及相关比例；骨性下颌角、下巴分类未实现。
- **F07 三庭**：条目显示待采集；未用人脸检测框顶部伪装发际线。
- **F08 五眼**：已有左右眼宽、内眼区极值间距等真实比例；完整五眼留白与参考阈值待精细轮廓模型。
- **F09 黄金三角/下巴**：已有点位展示；完整定义及角度规则未实现。
- **F10 眉部**：已实现两侧眉端点倾角；眉粗细、弯度与分类待专项规则。
- **F11 眼部**：已实现左右眼高宽比/眼宽占比；内眦角与眼型分类待精细标注模型。
- **F12 鼻唇**：已实现鼻部宽度、唇高宽、中心线上下唇厚度比；侧面鼻唇角待侧脸采集。
