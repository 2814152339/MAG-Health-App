# GitHub 云端编译与测试

## 当前状态与范围

已加入 `.github/workflows/ios.yml` 和 `scripts/ci-ios.sh`。**仅配置文件落地不代表云端运行成功**：推送到 GitHub 后，必须以对应 commit 的 Actions 运行状态、日志和产物为准。

本工作流编译 **iOS Simulator App**，运行共享 `Ruyuan` scheme 中的单元测试和 UI 测试；不生成签名 IPA，不发布到 App Store/TestFlight，也不要求 Apple ID、开发者证书、描述文件或服务器令牌。

## 如何触发与查看

1. 将本项目推送到仓库的 `main` 分支，自动触发 **iOS Simulator Build & Test**。
2. 或进入仓库 **Actions → iOS Simulator Build & Test → Run workflow**，手动运行。
3. 打开该次运行，查看 `simulator` 作业；确认它关联的是要验证的 commit。绿色表示编译、测试和产物上传全部成功；排队/运行中不等于成功。
4. 下载页面底部 `Ruyuan-iOS-Simulator-运行编号-尝试编号` 的 Artifacts，保留 7 天。失败时也会尝试上传已产生的诊断结果；作业被取消、硬超时或 runner 中断时不能保证上传完成。

每次运行最多 30 分钟。同一分支有新运行时会取消旧运行，避免重复消耗。私有仓库可能占用账号的 Actions 额度；请在 GitHub 的 Billing/Actions 设置检查额度与预算。

## 环境和产物

- 固定 `macos-15`，显式使用该镜像已安装的 **Xcode 16.4**。如果 GitHub 以后移除此 Xcode，工作流会明确失败，需要按官方镜像列表更新；不会静默下载或切换未知 SDK。
- 按当前 Xcode 的 simulator SDK 上限，从已安装、可用的 iOS 17 及以上 runtime 中选最新的兼容 iPhone 模拟器，自动启动并等待就绪，不硬编码设备 UDID。
- 关闭代码签名；实时输出原始 `xcodebuild` 日志，并保留真实退出码，不让 `tee` 把编译失败变成成功。
- 产物可能包括 `Ruyuan-Simulator.app.zip`、`Build.xcresult.zip`、`Test.xcresult.zip`、构建/测试日志、模拟器环境 JSON 和 `status.txt`。只有相应阶段实际执行产生的文件才存在。
- 先编译并打包 `.app`，再运行测试：测试失败时仍可下载已编译的模拟器 App；编译失败不会凭空产生 App。
- 上传仅限脚本生成的上述文件，不上传整个工作目录、个人照片、模型文件、后端数据库、`.env` 或证书。测试使用工程中的示例与合成输入。

**`.app` 是模拟器程序，不是 IPA，不能安装到真实 iPhone。** 下载并解压后，在安装了兼容 Xcode/runtime、架构匹配的 Mac 上可运行：

```bash
# 先在 Xcode 打开并启动一个兼容的 iPhone Simulator。
xcrun simctl install booted /absolute/path/to/Ruyuan.app
xcrun simctl launch booted com.ruyuan.aesthetics
# 在 Xcode 查看下载并解压的测试报告：
open /absolute/path/to/Test.xcresult
```

真实相机、真机性能及签名安装仍需真机验收。以后需要 TestFlight/签名 IPA 时，应单独配置最小权限的签名/分发工作流与 GitHub Secrets，不将私钥、密码或描述文件提交到仓库；本次未配置该功能。

## 在 Mac 复现 CI

```bash
cd /absolute/path/to/RuyuanAesthetics
DEVELOPER_DIR=/Applications/Xcode_16.4.app/Contents/Developer bash scripts/ci-ios.sh
```

若使用其他完整 Xcode，可先在 Xcode Settings → Locations 选择对应 Command Line Tools，再不带 `DEVELOPER_DIR` 运行。默认输出在独立的 `.build/ci/时间-进程号` 目录，也可用 `CI_ARTIFACTS_DIR` 指定一个**新的空目录**；不自动删除旧结果。

仅做日常本机构建也可沿用 `bash scripts/build-mac.sh`，测试用 `bash scripts/build-mac.sh --test`。Windows 上的结构或语法检查不是 Xcode SDK 编译或 XCTest 的替代品。
