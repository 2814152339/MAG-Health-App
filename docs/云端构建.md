### 触发与下载

1. 推送 `main`，且改动 `iOS/**`、`scripts/ci-ios-device.sh` 或 `.github/workflows/ios-device.yml` 时，自动触发 **iPhone Unsigned IPA Build**。
2. 也可进入 [真机工作流页面](https://github.com/2814152339/ruyuan-aesthetics-ios/actions/workflows/ios-device.yml) → **Run workflow** 手动运行。
3. 查看 `iphone` 作业，确认本次 commit 和完成状态。成功后下载底部 `Ruyuan-iPhone-Unsigned-运行编号-尝试编号` 的 Artifacts。
4. 解压外层 ZIP，取出 `Ruyuan-iPhone-Unsigned.ipa`。不要改动 IPA 本身；按 [Windows 安装指南](iPhone安装.md) 用本机工具及自己的 Apple ID 签名安装。

**未签名 IPA 不能直接在手机点击安装，不是 App Store / TestFlight 包。** 免费 Apple ID 的开发签名有效期通常为 7 天，需刷新；账号凭据只在你自己的电脑输入，不交给助理、不写进仓库。该第三方本地签名路径与付费 Apple Developer / TestFlight 分发是两回事。[Sideloadly 官方说明](https://sideloadly.io/)

### 真正编译了什么

- `macos-15`，使用镜像已安装的 Xcode 16.4，不下载额外 SDK。
- `Release`、`-sdk iphoneos`、`-destination generic/platform=iOS`，显式关闭签名，不需要证书、描述文件、Apple ID 或服务器令牌。
- 校验 Mach-O 为 `arm64` / `IOS`，拒绝模拟器二进制，并核对 `iPhoneOS` 平台；不是将模拟器 App 改后缀冒充 IPA。
- 将真实 `Release-iphoneos/Ruyuan.app` 打入 `Payload/Ruyuan.app`，检验 ZIP 完整性并记录 SHA-256。
- 本流程不运行 XCTest，不连接你的手机；真机安装、相机、性能与具体设备兼容性仍需你手机验收。

### 产物与失败证据

可能包含 `Ruyuan-iPhone-Unsigned.ipa`、`build.log`、环境/二进制校验日志、`status.txt`、`ipa-contents.txt` 和已有的 `Build.xcresult.zip`。只有相应阶段真实产生的文件才存在；编译、校验或打包失败不伪造 IPA，也不沿用旧产物。

运行限时 25 分钟，产物保留 7 天。同一分支的新运行会取消旧运行。失败也尝试上传已有诊断，但取消、硬超时或 runner 中断不能保证完成上传。私有仓库可能占用账号 Actions 额度，按需查看 GitHub Billing/Actions 的额度与预算。

## 有 Mac 时复现

在项目目录运行：

```bash
# iPhone 真机未签名 IPA
DEVELOPER_DIR=/Applications/Xcode_16.4.app/Contents/Developer bash scripts/ci-ios-device.sh
# 手动模拟器编译与 XCTest
DEVELOPER_DIR=/Applications/Xcode_16.4.app/Contents/Developer bash scripts/ci-ios.sh
```

若使用其他完整 Xcode，先选择对应 Command Line Tools。真机脚本默认输出至独立 `.build/iphone-ci/时间-进程号`，模拟器脚本至 `.build/ci/时间-进程号`；也可用 `CI_ARTIFACTS_DIR` 指定**新的空目录**，不自动删除旧结果。日常模拟器本机构建仍可用 `bash scripts/build-mac.sh`，测试加 `--test`。Windows 的结构或语法检查不能替代 Xcode 编译。
