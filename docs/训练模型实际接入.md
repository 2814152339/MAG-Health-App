# 本地训练模型实际接入与版本清单

核验日期：2026-11-12。这里记录本轮**已经下载、校验、运行并接入后端报告**的能力；不再把它们仅列为调研候选。iOS 本机默认算法仍与可选服务器推理分开，后端运行通过不等于新能力已经装入用户手机。

## 已落地的管线

授权本地照片 → 已有曝光/人脸检查 → Google FaceLandmarker 真实点位 → 面部包络加 2.5% 边距裁剪 → 三个固定版本 ViT 分类器 → 报告分项原始类别、模型置信度及来源。

- 实现：`backend/ruyuan/trained_skin.py`，由生产 `analyzer.py` 真实调用，没有生产假模型开关。
- CPU：PyTorch **2.9.1+cpu**，Transformers **4.57.6**，Safetensors **0.7.0**，Hugging Face Hub **0.36.2**；使用本项目 `backend/.venv`。
- 只加载内置 ViT 架构、固定 JSON 与 `.safetensors`，`local_files_only=True`；不加载 `optimizer.pt`、pickle checkpoint 或仓库自定义 Python。
- 不运行时下载。每个模型显式给出 `disabled` / `not_downloaded` / `checksum_mismatch` / `runtime_not_installed` / `ready` / 推理失败状态。
- 报告的 `trained-acne`、`trained-wrinkles`、`trained-skin_type` 分项来自模型本次输出；类别分布单列。训练分类器不生成像素病变 mask、病变计数、含水量、肤龄或临床准确率。
- 最高类概率低于 0.60 时显示“不确定候选”；0.60 是界面提示规则，不是经过人群验证的校准阈值。

## 下载来源与可复现执行

本机直连 huggingface.co 超时；本轮模型文件及固定版本元数据经 **hf-mirror.com 传输**，作者来源仍为上列 HF 仓库。该传输来源记录在 manifest 和本地下载回执中，不把镜像访问冒称主站直连成功。哈希固定的是本次复核版本；原作者的代码/权重许可与训练数据权利分别保留核对记录。

```powershell
# 仅在本项目目录运行；不触碰其他项目环境。
backend\.venv\Scripts\python.exe -m pip install torch==2.9.1 --index-url https://download.pytorch.org/whl/cpu
backend\.venv\Scripts\python.exe -m pip install -r backend\requirements-models.txt
backend\.venv\Scripts\python.exe scripts\download_skin_models.py --endpoint https://hf-mirror.com
```

下载器默认主站；镜像为显式选项。按固定字节数/摘要验证，支持 `.part` 中断恢复和原子改名；不读取或上传任何用户照片。权重、下载回执、照片和测试产物均在忽略目录，不进 Git。

启用生产分析器的可选训练模型：

```powershell
$env:RUYUAN_FACE_MODEL = (Resolve-Path backend\models\face_landmarker.task).Path
$env:RUYUAN_SKIN_MODELS_DIR = (Resolve-Path backend\models\skin).Path
$env:RUYUAN_SKIN_MODELS_REQUIRED = '1' # 不完整时本次任务明确失败；默认0则保留基线并列缺项
```

API 令牌仍按既有后端文档设置。新增 **`GET /v1/models`** 使用原有 Bearer 鉴权，返回公开模型版本/就绪状态，不泄露本机路径、令牌或照片内容。原上传同意、owner、幂等、取消、删除与报告权限流程保持不变。

## 本轮真实执行证据

授权的参考视频 **0012 帧**在本机处理；画面是带眼镜的屏幕录制照片，不是经标注的准确率验证集。

一次实际自动人脸裁剪后的结果：

- acne：`level -1`，softmax **84.6%**。
- wrinkles：`non-wrinkle`，softmax **96.1%**。
- skin_type：最高类 `oily`，softmax **41.8%**，明确显示**不确定候选**。
- 冷进程包含人脸检测、权重加载和三模型推理，共 **6.72 秒**；不是稳定暖机延迟或 iPhone 耗时。
- 全部生理评分仍为空；没有用上述概率伪造五维百分制或局部病变图层。

私有报告与回执保存在 `.build/model-runtime-smoke/`，不含入库或云端上传动作。实际测试命令：

```powershell
$env:RUYUAN_RUN_REAL_MODELS = '1'
backend\.venv\Scripts\python.exe -m pytest -o addopts='' -q backend\tests --junitxml=.build/model-runtime-smoke/tests.xml
```
