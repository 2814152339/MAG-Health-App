# 专项模型补缺核验（2026-11-12）

核验范围：F18 肤龄/参考人群百分位、F21 照片水分、F24 屏障/敏感、F25 病变像素分割、F26 毛孔/黑头、F14 眼袋/泪沟。以下区分已下载运行、等待资源授权、未采用；不把普通年龄模型换名为肤龄。

## 1. 本轮新增可执行资源：Pore-Net

- [作者源码与权重](https://github.com/ZombaSY/Pore-Net-release)，固定提交 `6f851e0d911bd73f41dd905c685129b13d52e1bc`；仓库 Apache-2.0，权重随同仓库发布，完整许可已保留。
- [作者公司原论文页](https://www.lulu-lab.com/bbs/board.php?bo_table=library&wr_id=3)明确研究目标是自拍相机的面部毛孔分割；[原论文](https://doi.org/10.1109/CBMS55023.2022.00062)。这不是材料孔隙、指纹或通用分割模型。
- 原权重 27,390 bytes，4,793 个参数；SHA256 `a2d0f5f20eee45197612d55d2404ef988832dbcd50dc949bfcd16f5978711da7`。源码、预处理、公开样本/GT/ROI 的地址和校验和见 `docs/models/pore-net-source.json`。
- 已完成本地真实 PyTorch 推理、5 项单元/实权重测试及真实 macOS Core ML 转换。云端运行 `43135425372`，产物 `13906908465`，未向云端提交用户照片。
- `PoreNet.mlmodel` 为独立 neuralNetwork FP32 文件，20,579 bytes；SHA256 `30a8f1e7dc88ae540769c90d9527c3bd93b13f149b748652d0ff14ab390a129c`。输入 RGB 1024×1280，输出 `poreProbability` 的实际形状为 `[1,1,1280,1024]`。
- 作者公开样本和两组合成图的 Core ML/PyTorch 最大像素概率差 `3.7551e-6`；阈值 0.25/0.4 的二值 mask 均无像素差异。公开单样本前景 IoU `0.42990`、Dice `0.60130`（0.25 阈值），并非整个自拍人群的测试指标。
- 交付定位：F26 的**毛孔候选概率/像素区域**。结合原生清晰度、面部皮肤 ROI、五官/胡须/遮挡排除后呈现；黑头类型仍无专项分类权重。仓库未公开完整训练数据授权链、参与者清单及独立测试划分，后续需向作者核对这些具体材料。

## 2. 六项补缺的实际选项

### F18：肤龄与参考人群百分位

[Ennsss/SkinAge](https://github.com/Ennsss/SkinAge) 是 MIT 训练框架：质量标签来自经典 CV 伪标签，年龄标签来自 UTKFace；README 要求先训练，未提供可直接下载的专项已训练权重。其年龄头对应数据集年龄，不能作为已验证的皮肤生物年龄。未纳入 App。

实施路线：先建立明确版本的同采集协议、分年龄/肤色/性别参考样本和专家分级，再对相同算法量计算分层经验百分位。当前三个分类器 softmax、单人历史排序、通用人脸年龄均不充当人群百分位。此次未找到具备公开授权、专项肤龄权重和可复算常模的即用组合。

### F21：照片水分

优先资源是 [NIA 作者代码](https://github.com/leejeongho3214/NIA)与[项目/评测页](https://leejeongho3214.github.io/NIA/)，论文 [10.1111/srt.70375](https://doi.org/10.1111/srt.70375)。包含真实 Corneometer 等仪器标签及受控手机/平板/DSLR 采集，不是把 dry 分类概率换算为含水量。

具体资源门槛：代码 MIT；checkpoint 压缩包明确要求向作者 `72210297@dankook.ac.kr` 申请密码。原始 [AI-Hub 71645 数据页](https://www.aihub.or.kr/aihubdata/data/view.do?aihubDataSe=data&currMenu=&dataSetSn=71645&topMenu=)注明仅本国人可申请，海外使用需核对授权渠道。未获取密码、未下载其权重、未自动发送邮件。下一步申请指定 hydration regression checkpoint、其权重商业再分发许可、采集协议及参与者隔离测试清单。

排除项：[Glowlytics 模型卡](https://huggingface.co/mufasabrownie/glowlytics-skin-models)披露教师标签来自 Claude Sonnet 4，对 UTKFace/FFHQ 图像打分；其 hydration 相关系数是相对教师标签，不是与水分仪的一致性证据。因此未作为实测水分接入。

### F24：屏障/敏感

[skin_TDA](https://github.com/kosekei/skin_TDA)提供 MIT 代码及部分派生数据；[原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7749164/)使用数字显微镜图像、TEWL/Corneometer/Skicon 测量与环境信息，报告特定测试条件下的 TEWL 回归结果。原图需要向作者申请，仓库树中未找到可直接加载的预训练回归权重。它适合作为后续配对采集/训练方案，不是自拍敏感诊断模型。

NIA 的生理值研究也不等于“敏感皮肤”或“屏障受损”标签。当前 App 保留问卷自报来源，照片偏红作为独立可见现象。下一步资源目标是有受试者授权的自拍＋TEWL/症状问卷配对数据，并分别验证两个目标。

### F25：病变像素分割

[RihemXX/Acnes 模型及代码](https://huggingface.co/spaces/RihemXX/Acnes/tree/main)提供 ResNet34 U-Net 二值痘相关候选分割，HF 权重提交 `79182ede8d14cb44de63b4f6ace1fa2a5a7a3d83`，97,920,000 bytes，SHA256 `c58a6af6fb622d916e4aa788d9f620d59df4a42209f655ce4a9db49686c05697`，Space 元数据为 Apache-2.0。

[作者 GitHub](https://github.com/rihem-bs02/Acnes)的评测说明承认，所述 98% pixel accuracy/91% IoU 缺少精确数据清单、划分、预测日志及评测配置。其 Github 旧文件与 HF 新 state_dict 大小不同，不互相替代校验，不以其宣传数字作为项目检出率。

**已新增真实本地执行**：下载并核对上述 HF 新权重的完整大小/SHA256，`torch.load(weights_only=True)` 得到 278 项纯 tensor state，SMP 0.5.0 的 ResNet34 U-Net 严格加载全部匹配，24,436,369 个参数。作者固定 GitHub notebook 只作为源码资料读取，未执行；实际预处理为 uint8 RGB 经 OpenCV `INTER_LINEAR` 拉伸到 256×256，再做 ImageNet mean/std。独立实现为 `backend/ruyuan/acne_segmentation.py`；5 项合同/真实权重测试通过，尚未注册到原共享 backend pipeline。手机 Core ML 转换/接入由另一路进行，此处不把 PyTorch 实跑写成已在 iPhone 运行。

作者公开 `original.jpg`（512×512，SHA256 `b4cc2a6fe3504c9fb6528459e3f53215d3993a5d3a8252b989ee93b01cf8ba79`）真实运行输出 Float32 `[1,1,256,256]`，阈值 `>0.20` 有 1,353 个候选像素，最大概率 `0.90859818`；均匀 RGB 和固定随机图候选为 0。该公开图未附像素 GT，因此没有据此计算 IoU/Dice/准确率。概率和候选 PNG、逐点/环境回执保留在忽略的 `.build/acne-segmentation-verification/`，可用 `scripts/probe_acne_segmentation.py` 复算。来源大小/hash/许可及训练资料缺项单独固定在 `docs/models/acne-segmentation-source.json`，Apache 原文保留在 `third_party/acne-segmentation/LICENSE`。输出限于二值痘相关候选，不据此细分丘疹/脓疱/粉刺等病理类别。

另核对并真实下载了 [Merligus/acne-segmentation](https://github.com/Merligus/acne-segmentation) 的 SegFormer-B0：作者仓库 MIT，固定提交 `9ad1243e0edb55d9d5976631198456d6449b13ff`；权重 14,973,702 bytes，SHA256 `886e2646aa456088916e5120b56c167f4fcdb1470a7b44dcd4e1cee0ff90cba1`，Git blob `a744d3b4fa91d0c213e4789a5da5780cc7227a31` 与仓库树一致。安全 tensor 加载、标准 SegFormer-B0 配置 `strict=True` 全匹配；512×512 输入的原 logits 为 `[1,2,128,128]`，按作者方式上采样并对第 1 通道 sigmoid 后得到 `[1,1,512,512]`。实际合成测试发现固定随机纹理图会产生 51,249 个候选像素，而均匀色图为 0；未将其并入 App。作者 README 的 IoU 0.4683 属作者表格，未在本机复现其数据集评测；代码训练/测试清单与模型的数据授权及像素标注来源仍需核对，尤其不能以仓库 MIT 覆盖 ACNE04 原始用途条款。

另一条常见路径 ACNE04 的[原作者仓库](https://github.com/xpwu95/LDL)明确仅学术免费，其他用途联系作者。基于 ACNE04 的第三方 YOLO/SegFormer 仓库换成 MIT/Apache 标记，也不自动补齐数据许可。下一步应申请作者完整训练来源及商业用途/权重许可，或用已授权的逐像素标注重新训练二值/多类模型。普通病变名称、痣/色斑/痘型仍需独立标注目标。

### F26：毛孔/黑头

毛孔已落实为第 1 节的 Pore-Net。黑头需要有鼻部粉刺/毛囊/鼻孔/胡须负样本的独立标签和权重；不把毛孔 mask 或鼻部局部暗点自动改名为黑头。新增资源的性能验证及原生清晰度门槛保留独立来源。

### F14：眼袋/泪沟

[lqrhy3/skin-disease-recognition](https://github.com/lqrhy3/skin-disease-recognition)的作者说明黑眼圈数据因隐私未开放，尝试 U-Net 后改用无监督方法；仓库没有可直接采用的专项公开权重/完整授权组合。

[泪沟分级原研究](https://pubmed.ncbi.nlm.nih.gov/39151284/)使用 504 位患者的 983 张同手机照片和 MAIA 软件，测试 F1 为 0.49；公开摘要未提供源码或权重下载。它是研究路线，不是现成开源包。下一步需获取带 Barton 分级/眼袋标签的同意授权样本，区分结构性凹陷、膨出和眼下阴影；当前仅呈现独立的眼下明暗/纹理指标。

## 3. 当前已接入三个分类器的数据来源核对

1. [skintelligent-acne](https://huggingface.co/imfarzanansari/skintelligent-acne)明确 checkpoint MIT；[skintelligent-wrinkles](https://huggingface.co/imfarzanansari/skintelligent-wrinkles)元数据 MIT。两张模型卡都未披露完整训练数据来源、图像权利/参与者同意、受试者隔离划分和可复算测试集。应向该作者申请这些具体材料，不能仅据同名其他项目推定它们使用了 ACNE04。
2. [skin_types_image_detection](https://huggingface.co/dima806/skin_types_image_detection)为 Apache-2.0。[作者 Kaggle notebook](https://www.kaggle.com/code/dima806/skin-types-image-detection-vit)的官方 API 返回数据源 `shakyadissanayake/oily-dry-and-normal-skin-types-dataset`；[该数据集](https://www.kaggle.com/datasets/shakyadissanayake/oily-dry-and-normal-skin-types-dataset)官方 API 标记 Apache 2.0，但说明中未交代逐图来源、采集同意及分型标注协议。
3. 该公开 notebook 先对文件集合做 RandomOverSampler，再随机 train_test_split，并非受试者隔离验证；重复图像可能跨集合，应另做去重/受试者隔离评估。此为对公开代码顺序的核验，不把它等同于已经证实原发布 checkpoint 的每一步训练过程。模型卡 65.34% 是作者报告，不是本项目在 iPhone 自拍上的准确率。
4. 不采纳 UTKFace/FFHQ 伪水分/伪肤龄的商业授权捷径：[UTKFace 原页](https://susanqq.github.io/UTKFace/)规定非商业研究；[FFHQ 原仓库](https://github.com/NVlabs/ffhq-dataset)区分单图许可和数据集 CC BY-NC-SA 4.0，部分原图也是 BY-NC。第三方权重的 MIT 标记不等于已核验这条训练数据授权链。
