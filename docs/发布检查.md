# Mac 构建与发布检查

## 打开与构建

- 安装完整 Xcode 16 或更新版本，首次启动完成许可、iOS SDK、Simulator runtime。
- 打开 `iOS/Ruyuan.xcodeproj`，选择 `Ruyuan` Scheme。
- 模拟器 ⌘R；终端 `bash scripts/build-mac.sh`；测试 `bash scripts/build-mac.sh --test`。
- 真机选择 Team，配置唯一 Bundle ID，开启设备开发者模式。不能通过 Windows 直接签出可安装 IPA。
- 无外部 Swift 包依赖；工程附共享 Scheme，不需要安装 XcodeGen。

## 真机验收

- 首次相机权限、拒绝/受限、系统设置恢复、前后切换、拍摄、重拍、退出停止相机。
- 锁屏/来电/前后台切换；相片方向与前摄镜像；原图、线条和图层对齐。
- 系统相册照片/HEIC/大照片/iCloud 照片；空选择、加载失败、单人/多人/无人脸。
- 小屏、大字体、VoiceOver；深色系统当前固定浅色主题。
- 报告保存、重启恢复、PDF分页/中文/分享、单份删除、全部清除和同意撤回。
- 真机帧率、内存峰值、发热、耗电、崩溃；目前未填写未经测试的性能数据。

## 服务端联调（可选）

- 配置后端随机令牌，审核 MediaPipe 模型与实际部署环境。
- 使用 HTTPS 域名；局域网 HTTP 仅用于受信网络联调。App 不全局关闭 ATS，不跟随携带照片/令牌的 HTTP 重定向。
- iPhone 访问电脑时不要填写手机自己的 127.0.0.1。确认防火墙、证书和局域网访问权限。
- 真机检查超时、断网、重启恢复、上传中取消、未知回执后恢复、服务端缺失模型、删除失败。
- 按实际吞吐/用户数升级任务队列、数据库、对象存储、账户鉴权与配额。

## TestFlight / App Store

- 客户 Apple Developer 团队、Bundle ID、签名、测试设备与 App Store Connect 记录。
- 更新正式 App 名称、版本、支持机型、隐私政策 URL、支持入口、截图和应用描述。
- 核对 `PrivacyInfo.xcprivacy` 与 App Store 隐私表：当前模板为本机默认流程；若上线服务端数据采集，按实际用途更新照片/分析结果类别与说明。
- 上传提示、同意/撤回、原图与报告留存/删除、备份策略正式评审。
- 专项模型实测数据、指标定义与低置信处理，专业测肤分数按验证结果逐项启用。
- 先内测，再分发 TestFlight；真实审核/签名/IPA/上架目前均未执行。
