# 开源模型与本轮接入核验

核验日期：2026-11-12（北京时间）。仅记录本轮实际读到的仓库、模型卡与文件页；未将照片上传到这些站点，已下载并核验下述实际接入模型；其他候选的状态分别列明。

## 已实际接入

- **Apple Vision**：本机人脸定位、二维五官特征点与拍摄质量筛查，由 iOS 系统运行；不是第三方开源皮肤检测权重。
- **RY-PhotoAppearance-v2**：本项目新写的确定性 RGB 图像算法，实际计算 sRGB/D65 Lab、ITA 参考角、高亮、相对偏红/色沉/细小暗点候选、四区线状纹理与眼下明暗差，并输出真实像素图层。
- 色彩均匀、纹理平整、线纹三项的公式均写在报告分项中，`scoreSource=photoHeuristic`。含水/皮脂仪数据未接入；敏感、水油的照片算法不生成生理测量分。后续问卷自评由独立 `selfReport` 来源标记。
- **Google SelfieMulticlass**：实际16,371,837字节，SHA-256 `c6748b1253a99067ef71f7e26ca71096cd449baefa8f101900ea23016507e0e0`，Apache-2.0；MediaPipe Tasks Vision1.2.2，六类真实mask已接入本机。
- **skintelligent-acne / skintelligent-wrinkles / skin_types_image_detection**：原始safetensors已固定revision/hash并在本机CPU完成真实自拍裁剪分类；三项CoreML转换与实际预测对照均通过，供iOS打包。详细制品见 `models/coreml-artifacts.json` 和 [训练模型接入](训练模型实际接入.md)。分类器无病变像素分割输出。
- **以下其他候选尚未接入当前 App**：状态依各项说明，不把公开模型资料当作用户照片的检出结果。

## 已接入：Google SelfieMulticlass

- 用途：将人物分成背景、头发、身体皮肤、面部皮肤、衣服、配饰六类。可用 face-skin 掩膜改进当前几何 ROI，再单独排除眉、眼、嘴、鼻孔。
- 许可证：Google 官方模型卡明确 **Apache License 2.0**。
- 体积：256×256 float32 版本约 **16.4 MB（15.6 MiB）**；实际包大小以下载的版本为准。它提供粗类别掩膜，不是毛孔、痘或皱纹模型。
- [官方任务与 iOS 使用文档](https://ai.google.dev/edge/mediapipe/solutions/vision/image_segmenter/ios)
- [Google 官方模型卡，含许可证和六类定义](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Multiclass%20Segmentation.pdf)
- [固定版本 1 模型文件](https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_multiclass_256x256/float32/1/selfie_multiclass_256x256.tflite)
- [Intel 官方示例，显示原文件约 15.6 MiB](https://docs.openvino.ai/2024/notebooks/tflite-selfie-segmentation-with-output.html)

## 其他可验证候选

### skintelligent-acne / skintelligent-wrinkles

- 类型：ViT 图像分类。痘模型输出整图严重程度类别；皱纹模型输出 wrinkle / non-wrinkle，不直接提供逐像素轮廓。
- 许可证：本轮作者模型卡标注 **MIT**；痘模型正文也明确 checkpoint 为 MIT。不要沿用其他项目 README 把它写成 Apache 的二手说明。
- 体积：痘模型 `model.safetensors` **343 MB**；整个仓库约 1.03 GB，含约 687 MB 的 optimizer，推理不需要整库下载。皱纹模型卡列出 85.8M F32 参数，本轮未取得可读的文件大小，不将参数估算写成实测体积。
- 接入前工作：核对训练资料授权与类别配置；用授权自拍做光线、肤色、机型、妆容分组验证。分类概率不转写成含水量或毛孔数量。
- [痘模型卡与许可证](https://huggingface.co/imfarzanansari/skintelligent-acne)
- [痘模型实际文件页](https://huggingface.co/imfarzanansari/skintelligent-acne/tree/main)
- [皱纹分类模型卡](https://huggingface.co/imfarzanansari/skintelligent-wrinkles)

### dima806 / skin_types_image_detection

- 类型：dry / normal / oily 三分类，ViT；作者模型卡测试集 accuracy **0.6534**（1,529 张样本）。
- 许可证：模型卡 **Apache-2.0**。
- 体积：推理 `model.safetensors` **343 MB**；整库 4.46 GB 含多份历史 checkpoint。
- 用法定位：已作为照片肤质分类接入本机后端，并完成CoreML实际CPU预测对照；iOS集成回归进行中，不把 dry 概率写成水分实测，不把 oily 概率写成皮脂量。
- [模型卡与作者测试报告](https://huggingface.co/dima806/skin_types_image_detection)
- [实际文件页](https://huggingface.co/dima806/skin_types_image_detection/tree/main)

### FFHQ-Wrinkle

- 类型：官方研究项目提供 U-Net、SwinUNETR 预训练检查点和皱纹像素分割推理代码。
- 授权：官方数据明确 **CC BY-NC-SA 4.0**，商业使用需另行核实许可；不能因代码或权重公开就直接写成商用免费。
- 官方数据包约 6.95 GB，这是数据量，不是模型体积。第三方 `rmsandu/ffhq-wrinkle-unet` 文件页列出 wrinkle 模型 **289 MB**、face segmentation **53.3 MB**，该模型也明确 CC BY-NC-SA 4.0。
- [官方仓库、预训练链接与授权](https://github.com/labhai/ffhq-wrinkle-dataset)
- [第三方模型实际文件页](https://huggingface.co/rmsandu/ffhq-wrinkle-unet/tree/main)

### skin-scan

- 类型：OpenCV + MediaPipe 本地热图 API，包含 Lab 偏红、HSV 高亮、DoG/LoG 暗点、纹理等规则管线。
- 许可证：仓库实际 LICENSE 为 **MIT**。
- 定位：参考模块划分、图层与 API 组织；其中水分等属于启发式代理，不是可直接采购或复用的仪器检测模型。当前 App 的 AppearanceAnalyzer 为本项目实现，未复制该仓库代码。
- [原仓库](https://github.com/DurtyDhiana/skin-scan)
- [实际 MIT LICENSE](https://github.com/DurtyDhiana/skin-scan/blob/main/LICENSE)

## 本轮排除的直接生产接入

**zikabyte / skin-problem-detection-demo**：模型页标 CC BY 4.0，但采用 Ultralytics YOLO26，需同时核对上游 AGPL/企业授权及训练数据权利。作者 held-out 测试的 acne mAP@50–95 为 **0.0989**、wrinkle 为 **0.1525**，本轮不把它包装为成熟检测能力，也未下载安装。

- [作者模型卡、数据来源与逐类测试结果](https://huggingface.co/zikabyte/skin-problem-detection-demo)
- [Ultralytics 上游许可证](https://github.com/ultralytics/ultralytics/blob/main/LICENSE)
