# 如愿美学 · 原生 iOS App

**v0.3 · 按参考视频逐项实施、持续验收。** SwiftUI 原生界面，最低 iOS 17，仅 iPhone 竖屏；不是网页套壳。本工程独立保存在如愿美学项目目录，功能与原规划 F01–F35 的对应范围见 [功能对照](docs/功能对照.md)。

## Windows + 自己的 iPhone

1. 在 [iPhone 真机云端构建](https://github.com/2814152339/ruyuan-aesthetics-ios/actions/workflows/ios-device.yml) 下载成功运行中的 `Ruyuan-iPhone-Unsigned-运行编号-尝试编号` 产物，解压外层 ZIP 取出 `.ipa`。
2. 用 Windows 本地签名工具和自己的 Apple ID 签名，通过 USB 安装到 iOS 17 及以上的 iPhone，无需先购买开发者会员。
3. 按 [iPhone 安装指南](docs/iPhone安装.md) 完成电脑信任、本人签名账号信任及开发者模式。账号密码仅在本机签名工具中输入。

**当前交付状态：**用户已自签安装旧 v0.1，并反馈与视频差距较大；本次针对这些缺项开发 v0.2。[v0.2 真机 Release 未签名 IPA 云编译已通过](https://github.com/2814152339/ruyuan-aesthetics-ios/actions/runs/43070754682)，对应 commit `7cb598f22ade728949a516e7a289a0a9a9f5a96d`。新 v0.2 尚未确认安装，也尚未完成真实 iPhone 相机与交互验收。

未签名 IPA 需要本地签名后安装；云编译成功不等于已经安装或完成真机测试。

## 当前已写入的流程与交互

- 首页、历史报告、我的与设置三个原生主 Tab；首次使用说明、授权与相册单图选择。
- AVFoundation 前后摄像头、重拍确认；**实时预览帧由 Vision 提供单人、居中、距离与姿态引导**，不是身份识别，不保存预览视频。
- 照片方向归一化、最长边 2560 的处理版 JPEG、去除来源元数据；分析、展示与持久保存采用同一张处理照片。
- **真实原照上的 10 个扫描分镜**：点位、轮廓下颌、纵向比例、五眼、三角下巴、眉眼、鼻唇、纹理、点状外观、眼周。分析阶段先显示真实任务状态，结果完成后播放对应真实点位与图层；支持暂停、继续与跳过，不拿播放百分比冒充计算进度。小屏首页固定检测/相册操作栏；报告缩略图采用明确尺寸和完整点击区域。
- **33 项新增二维几何条目 + 原有 19 项条目**，包含轮廓趋势、下颌折角、颏区比例、三角、五眼、眉弓、眼轮廓夹角、鼻唇等。52 是条目数，包含缺项与定义不同的相关指标，不代表 52 项都成功测出。
- 手动标记发际线后补充三庭；本人填写**实测瞳距**且照片检测到双瞳孔时，补充照片平面毫米估算。不用人均默认瞳距，也不把人脸框顶部当发际线。
- **11 个真实像素外观图层**：高亮、相对偏红、色沉候选、面颊暗点、鼻部暗点、四区线纹、眼下明暗区域、有效采样区；未达到阈值即为空图层。
- 聊天式报告、模糊隐私照片卡、摘要与五维列表、**五个 Tab 的详情弹层**、雷达图、分区线纹柱状图、分项缩略图和计算依据。
- 黑底全屏查看器，原图/图层切换、图例、缩放拖动、归位和点位查看。
- 本地赞踩与文字反馈；反馈保存在本机，不声称已提交服务器。历史记录、删除、PDF 导出与系统分享保留。
- 可选自托管后端、Keychain 令牌、持久任务键/ID、前台恢复、取消与幂等处理。

## v0.3 真实模型与实拍链路

- Google 官方 **Selfie Multiclass** 已固定原始模型与 SHA-256，MediaPipe 1.2.2 在 iPhone Release 实际编译通过。面部皮肤/毛发/配饰掩膜来自真实模型；可见发肤边界与手动标定并列保留。
- **痘外观、皱纹外观、照片肤质**三个公开训练模型已完成实际 Core ML 保存/重载/CPU predict 对照。痘与皱纹采用 FP16；肤质采用 FP32，修复 FP16 在近似并列样本上的 Top1 翻转，不放宽原门禁。模型固定版本、文件哈希及验证样本见 `docs/models/coreml-artifacts.json`。分类输出保留原标签与 softmax 置信度，不改写成病变位置或生理分。
- iOS 本机推理服务已接入正式拍照分析路径，依次加载和释放模型；CI 下载校验并编译进 App，手机运行不需要 API Key 或服务器。含全部模型的真机构建43134056850已通过，产物确含三个mlmodelc；模拟器43134057328的58个单元测试通过（包含三模型真实预测），4个UI中2个失败，正在按截图修复。
- **TrueDepth 同拍表面测距**已接线：同次照片像素绑定、绝对高质量深度、相机内参与畸变校正；实际有效端点才输出毫米。相册、普通前摄或无效深度保留二维。深度仅在本次内存使用，不上传、不存待恢复任务。SDK 16.4 原始头文件已核对畸变表方向，真实手机采集仍需设备验收。
- 首页原创3D头像、眉眼真实ROI放大、投影一致的箭头与标签、完整聊天式报告页面、十段暂停/前后/跳过扫描与真实语义层查看已写入；界面测试继续对照参考视频。

## 本机分析与分数来源

本机工作图最长边为 768；在实际像素上计算 **sRGB/D65 Lab、ITA 参考角、高亮/偏红覆盖、相对色沉与细点候选、额部/眉间/鼻唇侧/眼外侧线纹响应、眼下与双颊的 L* 明暗差**。几何排除眼、眉、嘴唇、鼻孔与下巴区域，并使用面颊颜色门控；已接入 Google Selfie Multiclass 六类真实语义分割，face-skin 与五官排除共同限定采样；头发和配饰分层保留。

报告分别保留两类来源：

- **`photoHeuristic`**：色彩均匀、纹理平整和线纹的照片视觉参考分，逐项给出实际公式。细点采样要求工作图长边至少 512、面部横宽至少 280 像素；不足时不强行计数或生成相应平整度分。
- **`selfReport`**：自愿问卷填写的干燥、出油、刺激反应频率，用独立规则整理水油与耐受感参考分；填写年龄仅作为本人自述年龄，不推断为肤龄。

照片观察与问卷不混成同一数据来源。五维全部有值才计算算术均值；缺项留空，不补零、不套示例值。图层候选不包装成已经验证的私有模型精确检出。

### 仍需接入的能力

逐像素痘型定位、经标注模型验证的真实毛孔/黑头检测、眼袋/泪沟/黑眼圈成因分类、肤龄与同龄常模、仪器含水量/皮脂量、皮肤屏障与弹性检测、真实解剖发际线（已提供可见发肤边界）、真实三维骨骼尺寸、侧面鼻唇角仍未实现。当前版本不是参考产品全部算法与全部功能的 100% 复刻。

[开源模型核验](docs/开源模型核验.md) 分开记录已实际接入的算法与仅完成调研的候选模型、权重体积及许可证；候选模型公开不等于已经部署。

## 可选后端

见 [后端说明](docs/backend.md)。附带 FastAPI、持久 SQLite 任务账本、私有本地图片、单进程 worker、同意记录、幂等上传、按操作键取消与完整报告契约。

默认不上传照片。启用服务器前，在「我的」填写服务器地址与令牌并保存。服务端 MediaPipe 模型须按文档配置；未配置时返回真实失败。生产 PostgreSQL/Celery/S3、多账户与运营后台仍属后续建设范围。
